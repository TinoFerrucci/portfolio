SynergyX-AI

Latest
GitHub ↗

Brief + CV parsing → Embeddings → FastAPI API (projects / talent / teams) → React + SQLite

SynergyX-AI matches a project brief in plain language to people with relevant skills. It recommends roles and identifies missing skills.

  • Embeddings match free-text project briefs to candidate profiles in a talent pool
  • CV parsing service that turns unstructured résumés into structured, comparable skill profiles
  • Each recommendation explains why the person was selected
  • FastAPI backend split into projects, talent, and teams routers, paired with a React, TypeScript, and Vite front end
  • Built for universities, hackathons, and innovation programmes that staff teams by hand

FIG 03

Datagentra

GitHub ↗

5-step agent → Read-only SQL guard → SQLite → SQL, chart, summary (OpenAI or Ollama)

Datagentra takes a question in plain English, generates SQL, explains the result, and suggests a chart.

  • Five-step agent: generate SQL, execute with retries, summarize, suggest a chart, and serialize
  • Read-only engine that blocks INSERT, UPDATE, DELETE, and DROP outright
  • Runs on OpenAI or locally via Ollama with three services orchestrated in Docker Compose
5-step agent · Read-only SQL guard · OpenAI or Ollama Python · LangChain · React · Docker · Ollama · TypeScript · SQLite
FIG 04

fastapi-fastmcp-autogen

GitHub ↗

MCP tools (FastMCP) ↔ Dynamic Pydantic models ↔ REST API (POST + Swagger)

The same handler can serve a REST endpoint and an MCP tool without duplicating route logic in either direction.

  • MCP to FastAPI: inspects registered tools, builds Pydantic models dynamically, and registers matching POST endpoints
  • FastAPI to MCP: walks defined routes, extracts their Pydantic models, and exposes them as MCP tools
  • FastAPI generates the Swagger documentation automatically
MCP↔REST bidirectional · Dynamic Pydantic models · Swagger docs Python · FastAPI · FastMCP · Pydantic · Uvicorn
FIG 05

Dog breed recognition pipeline

GitHub ↗

FastAPI 202 → 1. Search (pgvector) → 2. Classify → 3. Detect → Eval (NDCG@10, P/R/F1)

I wrote this computer-vision pipeline for the course I teach at UNR.

  • Three stages: similarity search over embeddings, supervised classification, and object detection
  • Async FastAPI returning HTTP 202 and job IDs, pgvector storage with cosine and L2 distance, and swappable embedding backbones
  • Students train their own models against it. Evaluation uses NDCG@10, precision, recall, and F1.
NDCG@10 scored · Async 202 jobs · pgvector PyTorch · FastAPI · pgvector · Gradio · Docker
