About

About me

My path in applied AI began with three years at Wiener lab., where I built internal assistants for technical support and customer service, along with document computer vision and data pipelines for clinical laboratory workflows. Today, contractor work with Apple through Tata Consultancy Services connects language models to enterprise data, APIs, and internal workflows using LangChain, LangGraph, and MCP.

At the Universidad Nacional de Rosario, I teach Computer Vision as an Auxiliar de Primera and previously taught Natural Language Processing on the same degree.

An earlier secondary technical degree in electromechanics led to the Tecnicatura Universitaria en Inteligencia Artificial from UNR, and the Licenciatura en Inteligencia Artificial is currently in progress.

Retrieval and evaluation

Search systems over technical manuals, PDFs, and databases combine hybrid search, metadata filters, and re-ranking so answers trace back to their sources. Grounding checks and business-rule filters keep responses tied to verified records.

Evidence: Wiener lab., Apple

Agents, MCP and the backend behind them

Tool-calling agent workflows on LangChain, LangGraph, and MCP connect language models to APIs and databases. These services ship with FastAPI and Docker for container deployment.

Evidence: Apple, Datagentra, fastapi-fastmcp-autogen

Computer vision and teaching

The three-stage course pipeline covers similarity search, classification, and object detection. In the UNR vision pipeline, I evaluate similarity search with NDCG@10. Teaching at UNR covers Computer Vision today and previously covered Natural Language Processing.

Evidence: UNR pipeline, UNR Computer Vision, UNR NLP

fastapi-fastmcp-autogen

Write your logic once, get both a REST API and a set of MCP tools. No duplicated handlers, in either direction.

  • MCP → FastAPI: inspects registered tools, builds Pydantic models dynamically and registers the matching POST endpoints
  • FastAPI → MCP: walks the defined routes, extracts their Pydantic models and exposes them as MCP tools
  • Swagger docs come along for free; near-zero configuration either way
